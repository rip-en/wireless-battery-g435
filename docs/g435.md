# Logitech G435 LIGHTSPEED receivers

The G435 does **not** speak HID++. Battery is only available through the dongle’s vendor bridge, and each read can briefly interrupt audio. The driver therefore caches the last reading for 30 minutes (5 minutes while the headset is off) and also refreshes when you click *Refresh now*.

| Receiver | USB ID | Bridge | Collection |
|---|---|---|---|
| Original Realtek | `046D:0ACB` | Realtek PA / bootloader | usage page `FFC0`, feature report 6 |
| Newer Holtek | `046D:0ADF` | Holtek CRC-16/XMODEM | usage page `FF00`, 64/65-byte reports |

## Realtek (`0ACB`)

1. Enter bootloader (`06 01 03`) — mutes USB audio while open  
2. Remote mode (`PA 0E E1 01`) so OTA commands reach the headset  
3. OTA get battery (`PA 06 00 31`) → reply contains `06 80 00 <mV LE16>`  
4. Local mode (`PA 0E E1 00`)  
5. Exit bootloader (`06 08 03`) — always runs  

Without remote mode the dongle answers with its own junk value (~102 mV). Only 3000–4500 mV is accepted.

Sources: [fr0styJS/g435-lightspeed-battery](https://github.com/fr0styJS/g435-lightspeed-battery), WirelessBattery PRs #72 / #93, endes’ DEV write-up.

## Holtek (`0ADF`)

1. Disable bridge power saving (`hid_cmd 0x85`)  
2. Confirm the headset is linked (`LQ E6`, bit `0x08`)  
3. Switch to remote mode if needed (`LQ E1 01`), read battery (`OTA 0x31`), restore local mode  

Sources: [DsGrilo/G435-Battery-app](https://github.com/DsGrilo/G435-Battery-app).

## Accuracy

Millivolts are exact. Percentage is a generic 3.7 V Li-ion estimate — Logitech publishes no G435 discharge table.
